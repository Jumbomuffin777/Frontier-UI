# PORT_MAP — upstream blocks vs hermes-port

Upstream src parts: p1/p2/p6 = Python resolvers, p3/p4/p4b/p5/p7 = HTML/CSS/JS renderer, p9 = Open WebUI tool class.
Hermes port replaces p9 with: agent-generated spec JSON + build_widget.py + sandbox-safe widget.
